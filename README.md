### 👋 Who we are

**M2 Software Solutions** is a software house building modern, scalable web applications for businesses of all sizes. We design and build **custom websites and systems for our clients**, from internal business tools to full customer-facing platforms.

### 🛠️ What we build with

- **Backend:** ASP.NET Core Web API, ASP.NET Core MVC
- **ORM:** Entity Framework Core (Code-First, Migrations)
- **Architecture:** Clean Architecture (Domain / Application / Infrastructure / Presentation layers), CQRS, Repository & Unit of Work patterns
- **Frontend:** Angular (Standalone Components, RxJS, Angular Material / Bootstrap)
- **Auth & Security:** JWT, Identity, Role-based Authorization
- **API Design:** RESTful APIs, Swagger / OpenAPI
- **Database:** SQL Server
- **DevOps:** Git, GitHub Actions, Docker *(as we scale)*

### 🚀 Current focus

We're actively building an **HR Management System** — an end-to-end platform covering employees, attendance, payroll, and leave management, built with ASP.NET Core, EF Core, Clean Architecture and Angular.

### 💼 What we offer

- Custom web application development (Full-Stack .NET + Angular)
- End-to-end business systems (HR, ERP-style internal tools, dashboards)
- Building and hosting **custom sites for our clients**
- API development & third-party integrations
- Ongoing maintenance & support
